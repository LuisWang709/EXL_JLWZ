## 2. AI models inside the product (runtime)

| Use | Model | Notes |
| --- | --- | --- |
| Classification, documentation drafting, documentation review (rater), rebuild code generation | Azure OpenAI `gpt-5-mini` in the demo (DeepSeek / OpenAI-compatible endpoints as a fallback) | One wrapper (`mrf.llm`) hides the vendor. CI and offline demos use a deterministic mock. |

Guardrails: numbers come only from tools (agents never compute them). The rater has veto rules for invented
variables or numbers. Inputs are screened for personal data and prompt injection (`mrf.core.guards`). Two human
gates (H1 documentation approval, H2 validation sign-off) come before any deployment.
