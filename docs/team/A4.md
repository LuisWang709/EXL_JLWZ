## 2. 需实现的 Python 接口

```python
class DataQualityChecker(Protocol):
    async def check(self, dataset_id: str) -> QualityReport: ...
    # 有 Dataset.schema_name → 用 A2 的 pandera schema；没有 → 通用检查（行数、缺失率、取值范围、列是否齐全）
    # 结构不符为 red，ModelRunner 据此抛 MRF-3101

class MonitoringRegistrar(Protocol):
    async def register(self, ctx: StepContext, cron: str | None = None) -> None: ...
    # 编排器在 deployed 后调用：保存 Schedule（默认 config/pipeline.yaml monitoring.default_schedule_cron）
```

监控任务（Container Apps Job，`python -m mrf.monitoring.job --model M001`）每批：质量检查 → `ModelRunner.run(kind="batch")` → 用 `mrf.validation.psi/csi` 计算漂移（**不要重新实现**）→ 写 `MonitoringMetric` → 按阈值生成 `Alert` → PSI > 0.25 或 Gini 降 > 5 点时，调用 A1 提供的 `trigger_revalidation(model_id)`，把流水线切回 `usability_run`。阈值全部读取 `config/pipeline.yaml: monitoring`。
