## 2. 需实现的 Python 接口（`mrf.contracts.agents`）

```python
class Rebuilder(Protocol):
    async def rebuild(self, ctx: StepContext) -> Rebuild: ...
    # 每调用一次 = 一次尝试：生成代码 → run_sandbox → run_parity → 返回 Rebuild(parity=...)
    # 失败时把差异摘要写进 Rebuild.feedback；编排器会把它放进下一次的 ctx.feedback
    # 不要在内部循环重试（重试计数归编排器）

class ModelRunner(Protocol):
    async def run(self, ctx: StepContext, dataset_id: str, kind: str = "usability") -> Run: ...
    # 先调 A4 的 DataQualityChecker.check，不通过抛 MRFError(MRF-3101)
    # 指标调用 A3 的 compute_metrics / mrf.validation，结果写入 MLflow 和 Run.metrics
```

还要提供：

```python
mrf.data.io.read_any(dataset: Dataset, **overrides) -> pd.DataFrame   # 支持所有 DatasetFormat
mrf.data.clean.clean(df, spec) -> pd.DataFrame                         # 缺失、截断、编码、切分
mrf.data.schemas.SCHEMAS: dict[str, pandera.DataFrameModel]            # A4 质量检查也用它
```

## 3. MCP 工具

| 工具 | 入参 | 返回 |
| --- | --- | --- |
