## 2. Python interfaces

```python
class Rebuilder(Protocol):
    async def rebuild(self, ctx: StepContext) -> Rebuild: ...
    # One call = one attempt: generate -> sandbox -> parity -> Rebuild.
    # Put differences in feedback; orchestrator supplies them to the next attempt.
    # Do not add an internal quality-retry loop.

class ModelRunner(Protocol):
    async def run(self, ctx: StepContext, dataset_id: str, kind: str = "usability") -> Run: ...
    # Call quality checking first; reject with MRF-3101.
    # Use A3 validation metrics; record Run.metrics and optional MLflow.
```

Also provide read_any(dataset, **overrides), clean(df, spec), and shared pandera SCHEMAS. The original plan includes missing handling, capping, encoding, splits and broad readers; actual support is listed in completion status.
