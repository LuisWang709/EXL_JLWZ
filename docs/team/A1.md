## 2. Shared Python interfaces

```python
from mrf.llm import get_llm, ChatMessage
res = await get_llm().chat([ChatMessage(role="user", content="...")], role="doc_writer", json_schema=MyPydanticModel)
# res.parsed / res.text / res.usage; transient backoff is centralized.

from mrf.storage import get_repo, get_blobs
repo = get_repo()
await repo.put("documents", doc.doc_id, doc)
await repo.get("documents", id, Document)
ref = await get_blobs().put_bytes("rebuilds/rb_1/model.py", data)

from mrf.mcp_server.client import get_tools
tools = get_tools()  # MRF_TOOL_TRANSPORT chooses inprocess/http.
result = await tools.call("search_kb", query="SS1/23 principle 3", top_k=5)
openai_tools = await tools.as_openai_tools(["parse_code", "search_kb"])
```

Tool owners implement typed functions in tools/*.py and add them to the tool collection.
