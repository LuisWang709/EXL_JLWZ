## 1. 对外 REST API（我负责的端点）

| 方法 | 路径 | 请求 | 成功响应 `data` | 主要错误 |
| --- | --- | --- | --- | --- |
| POST | `/api/v1/pipelines` | multipart：`files[]`、`model_name`、`owner?`、`dataset_ids[]?`、`options?`（JSON），或 JSON `PipelineCreate` | `{pipeline_id, model_id, job_id, poll}` 202 | 1001 类型、1002 大小、1005 注入、1006 请求体 |
| GET | `/api/v1/pipelines` | `page`、`page_size`、`state?` | `{items: Pipeline[], pagination}` | — |
| GET | `/api/v1/pipelines/{id}` | — | `Pipeline`（state、current_step、attempts、history、usage） | 1404 |
| GET | `/api/v1/models` | `language?`、`purpose?`、`needs_review?`、分页 | `{items: ModelRecord[], pagination}` | — |
| GET | `/api/v1/models/{id}` | — | `ModelRecord`（含 classification） | 1404 |
| GET | `/api/v1/reviews` | `status?`、`gate?`、分页 | `{items: Review[], pagination}` | — |
| GET | `/api/v1/reviews/{id}` | — | `Review` | 1404 |
| POST | `/api/v1/reviews/{id}/decision` | 请求头 `X-Operator`；`ReviewDecision{decision, comment?, edits?, target_state?}` | `{review, job_id}` 200 | 1404、3201（已决定或状态不符） |
| GET | `/api/v1/jobs/{id}` | — | `Job` | 1404 |

另外负责全局横切逻辑：`X-API-Key` 鉴权、`Idempotency-Key` 幂等、`X-Request-ID` 追踪、异常转信封、分页。

## 2. 我提供给队友的 Python 接口

```python
# LLM（11/3）
from mrf.llm import get_llm, ChatMessage

res = await get_llm().chat([ChatMessage(role="user", content="...")], role="doc_writer", json_schema=MyPydanticModel)
res.parsed / res.text / res.usage  # 瞬时错误已退让 3 次；失败抛 MRFError(4001/4002/4003)

# 存储（11/3 内存版，11/5 SQLite，11/9 Cosmos）
from mrf.storage import get_repo, get_blobs

repo = get_repo()
await repo.put("documents", doc.doc_id, doc)
await repo.get("documents", id, Document)
uri = await get_blobs().put_bytes("rebuilds/rb_1/model.py", data)

# MCP 工具注册（11/5）——各负责人在自己的 tools/*.py 写函数，框架自动注册
# 智能体侧调用：
from mrf.mcp_server.client import get_tools

tools = get_tools()  # inprocess 或 http，由 MRF_TOOL_TRANSPORT 决定
result = await tools.call("search_kb", query="SS1/23 principle 3", top_k=5)
openai_tools = await tools.as_openai_tools(["parse_code", "search_kb"])  # 给 LLM function calling
```
