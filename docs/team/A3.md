## 2. Python interfaces

```python
class DocWriter(Protocol):
    async def draft(self, ctx: StepContext) -> Document: ...
    # One call per attempt; ctx.feedback contains rating/H1 comments.
    # Claims need Evidence(source=code|kb|data|tool, ref=...).
    # Numeric facts come from profiling/metrics tools, not LLM invention.

class Rater(Protocol):
    async def rate(self, ctx: StepContext, document: Document) -> Rating: ...
    # Rules 0-60 plus LLM 0-40; total >=80 and no veto to pass.
    # Comments must be actionable edits passed to the next draft.

class ReportBuilder(Protocol):
    async def build(self, ctx: StepContext, report_type: str) -> Report: ...
    # Analysis: consistency/performance/stability/fairness and process evidence.
    # Validation: H2 package; zero numeric mismatches against sources.
```

Frozen metric interfaces: auc/gini/ks(y_true, score); brier(y_true, prob); hosmer_lemeshow(y_true, prob, groups=10); psi(expected, actual, bins=10, binning="quantile"); csi(expected_df, actual_df, columns=None, bins=10); fairness(y_true, score, segment, threshold=None).
