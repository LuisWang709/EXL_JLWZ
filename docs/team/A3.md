## 2. 需实现的 Python 接口

```python
class DocWriter(Protocol):
    async def draft(self, ctx: StepContext) -> Document: ...

    # 一次调用 = 一次尝试；ctx.feedback 是上次 Rating.comments（或 H1 驳回意见）
    # 每个 section 中的每条论断都要有 Evidence(source=code|kb|data|tool, ref=...)
    # 数字只来自工具（profile_data / compute_metrics），不能让 LLM 编


class Rater(Protocol):
    async def rate(self, ctx: StepContext, document: Document) -> Rating: ...

    # rule_score(0-60) + llm_score(0-40)；passed = total >= 80 且 veto_flags 为空
    # comments 要写成可执行的修改意见（会原样喂给下一次 draft）


class ReportBuilder(Protocol):
    async def build(self, ctx: StepContext, report_type: str) -> Report: ...

    # analysis：一致性、表现、稳定性、公平性的红黄绿 + 流程提升（耗时/工时/成本/自动化率）
    # validation：H2 签核用；生成后自动核对每个数字与来源一致（0 处不一致）
```
